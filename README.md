#### 1. Create New Environment using VS code (not Conda)
###### python3.8 -m venv venv

#### 2. Create a gitignore file in Github
###### Create new file; Chose Options= Python

###### Setup.py is to build the machine learning project as a package
###### Create file on VS Code and name it Setup.py

### 4. Create a requirements.txt
###### Create a requirements.txt file to have the list of all packages needed to by installed on the repository
